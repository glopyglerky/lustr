## Why the original profiling check failed

The original qualifier exited 0 after checking the expected outcomes of all
15 commands, including rejection and recovery cases. The subsequent summarizer
reported:

```text
missing/extra compiler profile relative to independent request trace for dependency
```

The first two records in the original `qualification/dependency.trace` were:

```text
request-key=a8635c96722e5567 retained=falserequest-key=27b2ad9f5eece79d retained=false

```

The third request record was separately framed. All three corresponding
profile files contain the expected request identities. The summarizer requires
one complete request record per line; accepting arbitrary matching substrings
would weaken that independent coverage check. It continues to reject this
original trace.

The shared production helper used `writeln!(file, "{value}")` on an append
file. Formatting could write the value and final newline separately, allowing
another compiler process to append between them. The same helper writes the
multiline native emitter diagnostics. The correction constructs the whole
record and holds an exclusive `File::lock` across `write_all`, including any
short-write retries. Every mixed trace caller uses this shared helper. Tracing
remains opt-in; trace failures preserve the compiler result and leave missing
or incomplete evidence for the strict validator to reject.

The correction was authored at
`a1414d51dd725863eb0c1c8162e415a0408f3030` and applied as
`de5635e2c00a6d5c1c88de4baab4817cd446bf56`. The
[source manifest](profiles/2026-11-17-40d2ac3/source-manifest.json) records full
file identities and the exact retained helper excerpts. It confirms identical
production and test file bytes in the authoring and applied commits. The
profiler validation implementation is byte-identical to the measured version.

No duration, profile identity, native response, outcome or status is changed.
Of all 130 original inputs, only the declared dependency trace framing differs.

The strict reporter from the measured checkout reproduces the retained derived
summary across all 26 profiles and 15 commands, with all 35 successful native
responses bound to their client intervals and original emitter diagnostics.
Standards independently compared all 130 inputs and reproduced the same result.
