Preserve source in commits and existing references before removing active code.
Do not delete unique worktrees, rewrite shared history, erase failed tests or
claim an older package has been repaired retroactively. Removal from production
may reveal unsupported requests. Report that accurately; an honest failure is
not implementation of the missing Rust complement.

The next implementation record must state exactly which routes were removed,
which helpers/components remain, actual admitted partial imports, broad research
dependencies, meaningful validation and remaining full-compiler gaps.
