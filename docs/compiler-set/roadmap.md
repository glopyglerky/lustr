# Lustr roadmap

The [exclusive coverage contract](exclusive-coverage-contract.md) fixes the sole
destination: full Rust compilation through Lust for its covered work and
selective upstream implementation for the complement. The full Rust source
stays in blueFe. The [completion checklist](completion-checklist.md) is the
single current work register.

| Order | Deliverable |
| --- | --- |
| 0 | Reconcile active requirements and preserve unique code/evidence before retiring conflicting production routes. |
| 1 | Expose full actual Lust capabilities, checked state and typed outcomes; keep bridge gaps distinct from the complement. |
| 2 | Import and connect justified missing upstream operations with verified feature/target dependency closure and no duplicate Lust-owned compiler stages. |
| 3 | Complete shared semantics, instance/ABI/runtime ownership, genuine metadata and downstream artifact behavior. |
| 4 | Preserve precise retained-state invalidation across supported and complementary work. |
| 5 | Make the integrated boundary the normal standalone and Cargo route without whole-program retry or a hidden stock compiler. |
| 6 | Qualify the actual source-built package, Rust semantics and every advertised platform/profile. |
| 7 | Demonstrate near-Lust supported performance and near-rustc complementary performance separately, retain regressions, then publish the qualified package. |

A source manifest, route guard or scalar demonstration closes only its own
bounded task. It cannot establish the complete compiler. Useful correctness
repairs and provenance work continue alongside integration. Do not replace the
goal with independent Rust reimplementation, a memory-safety rewrite, broad
compiler tuning, a coordinator or all-Rust-source vendoring.

The [design checkpoint](design.md) separates pre-correction default `7cea76c9`,
historical candidate evidence, audited PR #32 `cb0721d4` and the documentation
merged through PR #31. The [implementation cleanup](exclusive-coverage-cleanup.md)
records removal of the conflicting routes and the remaining compiler work.
