fixture and 31 named controls. It joins actual completed native records and
emitted objects to selective original Rust metadata, then verifies an ordinary
Rust consumer. The earlier hosted failures are preserved separately. This
checkpoint does not qualify a public or retained compiler route, full Rust
coverage, near-Lust performance, an overall speedup, or a release.

## Failure and bounded repair

The construction fixture copied the encoder and SDK research crates but omitted
the new qualifier required by the unchanged source guard. The repair adds that
crate to the same fixture copy; it does not exempt the fixture from admission.

The freestanding object path unconditionally captured a native semantic
artifact's runtime source/location record. That record was unused on this path,
but obtaining its digest launched `sha256sum`. The repair limits that capture to
the explicit native semantic-artifact path, which still requires and validates
the runtime record. Freestanding objects retain the requirement that their
actual ELF undefined-symbol set be empty. The trace allowlist stays unchanged.

The corrected attempt above supplies the separate hosted result for these
repairs. It does not change the first attempt's failed outcome. Other CI jobs
and later source require their own records.
