# Native metadata join qualification

The original one-shot mode of this research executable consumes one actual native checked unit,
completes its declaration and emitted-instance records, invokes the selective
metadata encoder and constructs a Rust library archive. The candidate invokes
Clang for the existing native C emitter and the pinned LLVM object/archive
utilities. It does not invoke or link a full Rust compiler.
The captured Clang command disables implicit configuration and explicitly uses
no stack protector for the represented request. Windows control-flow guard is
disabled in this Linux target context. This Clang research emitter is separate
from stock Lust's TinyCC path and establishes no equivalent-speed claim.

The fixed scope is a flat ASCII/LF `no_std` library of ordinary safe nongeneric
`u64` functions, local calls and represented scalar bodies. It uses edition 2024,
Linux x86-64, optimization zero, no debug information and abort panic behavior.
No caller option is rewritten to bypass an obligation. The public compiler,
general library metadata and the wider complement remain unintegrated. The
retained mode below needs its own exact-source qualification. This is not a
compiler performance benchmark.

`tools/test-native-consumer-metadata.py` supplies a fixed independent source and
requires actual process tracing. After the candidate publishes its artifact,
the pinned original Rust compiler reads its metadata and compiles an ordinary
Rust caller using `--extern consumer=...`. The caller uses both direct calls and
Rust function values. No C declarations or direct object linker arguments can
stand in for crate metadata interoperability.

The campaign checks 262,152 explicit runtime assertions, public/private access,
signature/arity failures, a rejected private body, changed receipt/version
contexts and artifact preservation after publication failure. It also corrupts
actual completed/emitted mappings and creates actual missing/duplicate-member
archives. Each corruption must be rejected by the consuming implementation.
Successful oracle commands require empty stderr. Default mitigation records
must allow the ordinary caller while a stronger stack-protector request remains
incompatible. No warning is suppressed.

The former uncommitted campaign failed when the encoder omitted upstream's
disabled mitigation records. The current source restores the pinned original
`StackProtector(None)` and `ControlFlowGuard(Enabled(false))` records. A disabled
stack protector and an absent record have different meanings to the original
consumer. The new caller also binds the SDK receipt on the single read used to
construct its immutable facts.

`source-slices.json` identifies the original metadata object-wrapper branches,
their target assumptions, licenses and adapted files. Encoder source provenance
remains in its own inventory. Runtime generation facts stay native-owned; no
second parser, checker, MIR builder or complete driver is imported.

passed, with 262,152 runtime assertions and eight completely accounted actual
candidate traces. The original consumer compiled with `-Dwarnings` and empty

The earlier attempt's missing construction-fixture crate and undeclared

This finite campaign does not qualify every program in the admitted grammar or
integrate this executable into retained/public compilation. Later source and
broader coverage require their own evidence. `--functional-only` is an explicit
local diagnostic mode, leaves trace qualification false, and is not used by
required CI.

## Retained native candidate

`--retained SOURCE EXISTING_ROOT EXACT_SDK_RECEIPT PINNED_SDK` now drives one
actual native `Session` through caller-owned stdin/stdout JSON lines. This
candidate source has not yet been compiled or executed. The preceding hosted
result belongs only to its exact earlier source and one-shot Clang route.

The retained path fixes the library/profile/parser policy before its first
request. The ordinary native resolver and body patching supply the same
`PreparedRequest`, checked/lowered bodies, semantic reads and generated slots
used by the native driver. Checked expression facts use function-relative
indices and stable definition identities. Reuse requires current native passing
state, validated semantic reads and matching body/header identities. The common
completion boundary proves the whole current flat u64 call graph before total
code generation. Recursion and unrepresented syntax, lint or ABI obligations
return an integration gap; they are not treated as invalid Rust or delegated.

Native `Check` and dropped prepared continuations preserve their original
structural IR. Rebinding translates its original function-relative spans to the
current AST and checks the original native IR fingerprint. It does not recheck
or lower a body just to obtain an emission proof. Native emission uses the
original in-process TinyCC singleton-unit API and the original warm mimalloc
hook, once at setup. Each body has direct stable names, its exact generated
callee declarations and a separately cached object. Its mode has a distinct
code-generation identity. A failed object write invalidates old generated-C to
object joins before emission begins, so recovery cannot publish an older body.

The host loads the bound SDK once, validates actual object definitions and
callee relocations, encodes only completed native facts, and applies the original
LLVM symbol/archive utilities. Unchanged native objects retain their digests;
unchanged relevant symbol mappings retain renamed bytes. Exact no-ops retain
metadata and archive bytes without another encoder, object tool or archiver.
A prepared artifact cache can advance before publication; a separate immutable
last-published handle advances only after durable publication. Caller-requested
output copies and report writing still occur and are not a compiler speed claim.

The encoder binds a canonical producer-object inventory with the definitions
owned by each object. Its producer hashes precede symbol renaming; final member
hashes and the verified mapping are separate artifact evidence. No whole-library
recompilation or `ld -r` merge substitutes for narrow native emission.

The authored hosted campaign in `tools/test-retained-native-metadata.py`
predeclares 29 requests in one retained history. It covers source edits and
reverts, no-ops, declaration insertion/removal/reordering, changed signatures,
an invalid private body, a valid but unrepresented u32 interface, two checks
before a build, a dropped prepared continuation and its subsequent build,
partial TinyCC output failure, and stage/publication failure with recovery.
A native-output path conflict forces the second of two changed function objects
to fail; the next same-source request must use the current bodies and compile
only the remaining object. A valid u32 bridge refusal is a negative control,
not successful Rust coverage.

Separate fresh-session and SDK histories bring the declared campaign to
three sessions, with two additional setup refusals for changed SDK inputs. The
loaded SDK facts must remain immutable during a session; a fresh session must
refuse the changed receipt or dependency bytes. Original Rust consumers use
ordinary `--extern` libraries, direct calls and function values, including an
eight-argument u64 function that crosses the six-register argument boundary.
Successful fresh and retained builds must produce identical final artifacts.
The fixed ordinary-consumer inventory contains 25 successful reader/compile/run
triples and 6,815,952 runtime assertions; missing or duplicated consumers cannot
pass by reporting all request names.

The evaluator requires complete exec/socket traces, independently checks native
and renamed ELF bytes, local-call relocations, archive members and index entries,
and compares actual checked/generated/object inventories. Its 18 authored
synthetic evaluator controls remain separate from compiler evidence. The prior
one-shot campaign retains all 31 existing controls and adds five actual
producer-object ownership mutations. Only Python syntax and whitespace have
been checked for the new evaluator; none of these new checks has been executed
or qualified this source. Public Cargo/library entry integration, general Rust
coverage, restart images, broader host portability and matched speed remain open.
